Project 1 – Data Cleaning and Preparation

Tools Used
• Microsoft Power BI  Desktop (Power Query)

Project Objective
The objective of this project was to clean and prepare a raw dataset by identifying missing values, checking duplicates, correcting inconsistent data formats, and improving overall data quality for analysis.

Dataset Overview
The dataset contained transactional sales records including customer information, order details, coupon codes, and purchase records.

Data Cleaning Tasks Performed
• Imported dataset into Power BI
• Opened dataset in Power Query Editor
• Corrected incorrect date formats
• Checked for missing values
• Replaced missing CouponCode values with “None”
• Checked for duplicate rows and duplicate Order IDs
• Verified that repeated Customer IDs represented valid repeat transactions
• Corrected and standardized data formats
• Ensured overall data consistency

Duplicate Analysis
During the cleaning process, repeated Customer IDs were identified. After proper analysis, these were confirmed to be valid repeat customer transactions rather than duplicate records.
No duplicate transaction rows or duplicate Order IDs were found in the dataset.
